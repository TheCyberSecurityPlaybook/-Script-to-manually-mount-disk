### Как использовать:

1. **Создайте файл:**
   ```bash
   nano mount_adata.sh
   ```
   Скопируйте туда код скрипта выше.

2. **Дайте права на выполнение:**
   ```bash
   chmod +x mount_adata.sh
   ```

3. **Запустите:**
   ```bash
   sudo ./mount_adata.sh /dev/sdd2
   ```

### Для отмонтирования (optionally):

```bash
sudo umount /mnt/adata
```
